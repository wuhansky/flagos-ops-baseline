# Native GRU H800 records

`op_pytorch_h800_gru_native_baseline.json` is the unmodified official collector output: three native CUDA interfaces, six original core descriptors and four NVIDIA dtypes,24 records each. Forward/out/backward-out are distinct overloads; out buffers use their real keyword-only schema.

Producer commit: `e3776c2c1d4431da168f18577c690d7f807451e7`. Exact commands, artifact SHA and actual build provenance are in `gru_h800_native_collection_20261029.json`; each collection was preceded by a fresh assigned-device check. Collection used `tools/collect_baseline_nvidia.py --repo pytorch --device 0 --no-ncu` on an NVIDIA H800. Traffic/counter fields are unavailable, rather than inferred.

The actual Torch package reports an NV build identifier and `torch.version.git_version == Unknown`; its CUDA library SHA is recorded. An upstream PyTorch tag must not be substituted for this build identity.

The corresponding Ascend core consumes its original18 records per interface (three supported dtypes); the additional six FP64 records preserve the original NVIDIA grid. Input metadata includes all gates, optional biases, workspace, gradient, out buffers, strides and dtypes. These native NVIDIA measurements are external comparisons; target CPU-oracle bootstrap latency is measured separately and is not a NVIDIA baseline.
